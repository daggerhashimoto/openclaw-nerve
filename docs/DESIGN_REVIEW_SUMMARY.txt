================================================================================
COMPONENT NAMING CONVENTIONS - REFERENCE TABLE
================================================================================

PATTERN 1: Container Components
- Pattern: [Feature]Panel.tsx
- Examples: ChatPanel, SessionList, WorkspacePanel, KanbanPanel
- Purpose: Main container for feature area
- Usage: Root component of a major tile

PATTERN 2: Tab Systems
- Pattern: [Feature]Tabs.tsx + [Feature]Tab.tsx
- Examples: WorkspaceTabs + MemoryTab, CronsTab, ConfigTab
- Purpose: Tabbed interface organization
- Usage: Multi-view components within workspace

PATTERN 3: Dialog/Modals
- Pattern: [Feature]Dialog.tsx
- Examples: CronDialog, SpawnAgentDialog, CreateTaskDialog
- Purpose: Modal or dialog components
- Usage: User input forms, confirmations

PATTERN 4: List/Tree Items
- Pattern: [Feature]Item.tsx or [Feature]Node.tsx
- Examples: MemoryItem, SessionNode, KanbanCard
- Purpose: Individual list/tree items
- Usage: Repeating item in lists or trees

PATTERN 5: Subcomponents
- Pattern: [Feature][SubName].tsx
- Examples: ChatHeader, TaskDetailDrawer, ContextMeter
- Purpose: Feature-specific subcomponents
- Usage: Part of larger feature

PATTERN 6: Custom Hooks
- Pattern: use[Feature]()
- Examples: useOpenFiles, useCrons, useDashboardData
- Purpose: Stateful logic extraction
- Usage: Reusable state management

PATTERN 7: Utilities
- Pattern: [name].ts (lowercase)
- Examples: editorTheme.ts, fileTypes.ts, sessionKeys.ts
- Purpose: Functions and configuration
- Usage: Helper functions, constants
